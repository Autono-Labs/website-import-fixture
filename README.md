# Website import fixture

A made-up business's website, kept by Foundable as a test fixture: Foundable's tests bring the `website` folder into a
Foundable website from this public repository's address, pictures, font and video included. Nothing here is a real
business. The font is Plus Jakarta Sans under the SIL Open Font License 1.1 (`website/assets/fonts/OFL.txt`).

- `website/`: the site, plain HTML, CSS and JavaScript (three pages, two pictures, a font and a short video)
- `social/`, `writing/`: other material beside it, as a brand kit holds
